# Smart Waste Management System

A C-based Smart Waste Management System that helps users find the nearest dustbin based on their current location and waste type (Dry/Wet). The system calculates the shortest distance using the Euclidean Distance Formula and promotes efficient waste disposal.

## Features
- User Login Authentication
- Dry & Wet Waste Classification
- Nearest Dustbin Search
- Distance Calculation
- Input Validation
- Console-Based Interface

## Technologies
- C Programming
- Structures
- Arrays
- Mathematical Functions
- GCC / Code::Blocks

## Algorithm
The system filters dustbins based on waste type and calculates the Euclidean distance between the user's coordinates and available dustbins to identify the nearest disposal point.
